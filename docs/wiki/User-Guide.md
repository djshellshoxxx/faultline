# User Guide

- **Specimen buffer.** A rolling buffer of 4, 8 or 16 bars is analysed for onsets, spectral frames and level.
- **Surgeons.** Six parallel processes: STUTTER, GRANULAR, REVERSE, CORRUPT, REORDER and FREEZE.
- **Chaos.** Sweeps from repeatable destruction (trip hop, stutter) to non-repeating chaos (glitch, industrial).
- **Rhythmic Gravity.** Grid snap and swing, independent of Chaos.
- **Scale Lock.** Keeps pitched repeats in a chosen key.
- **Undo, redo and history rewind.** Gestures are committed as undo steps.
- **Capture and drag-out.** Drag captured audio out of the plugin.
- **Live and MIDI, sidechain.** Described in the README.

See the README sections for each control. [INSTALL.md](../../INSTALL.md) covers file locations and the macOS Gatekeeper step.
