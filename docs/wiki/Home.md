# Vivisect Wiki

Vivisect (repository `faultline`) is a sample-butchery VST. A rolling buffer of the input is analysed and six parallel "surgeons" cut, granulate, reverse, corrupt, reorder and reinject slices. A single Chaos control moves from grid-locked stutter to chaotic glitch. The [README](../../README.md) is the primary reference.
